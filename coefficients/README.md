# Coefficient files

Ready-made coefficient sets for `CoefficientPerTensorWeightQuant`, generated by a
`pow2_coeffs.py` script. All values are integers; calibration scales them by `2^shift`.

Format: plain text, one coefficient set per line, values separated by whitespace.
With several lines, calibration tries every set and keeps the best (lowest SAD,
within the clip ceiling). Use a file by setting `filepath` on a subclass:

```python
class MyCoeffQuant(CoefficientPerTensorWeightQuant):
    filepath = "coefficients/coeffs_all_pow2_n8.txt"
```

For each `n` from 2 to 12:

| File | Contents |
|---|---|
| `coeffs_single_pow2_n{n}.txt` | 1 line: 0 and ±2^0 … ±2^n |
| `coeffs_all_pow2_n{n}.txt` | 1 line: all pairwise sums of those values that lie within their range |
| `coeffs_comb{s}_pow2_n{n}.txt` (`s` = 1..4) | 10 lines: the 10 largest sets obtained by adding `s` extra sums (and their left shifts) to the single set |

All files together are about 270 KB. Calibration time grows with the number of lines
(10 sets x 13 shifts for the `comb` files, roughly 6-9 s on a large conv layer).
